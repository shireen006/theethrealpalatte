# Theethrealpalatte — Handmade Crochet & Original Art

Welcome to **Theethrealpalatte**, a boutique storefront web application crafted for handmade crochet accessories, home decor, and original paintings.

## Project Structure

- `theethrealpalatte/`: The main React 18 + Vite application.
  - `src/`: Components, configurations, images, styles, and entry point.
- `.planning/`: Complete GSD architecture, requirements, roadmap, and codebase mapping.

## Quick Start

```bash
# 1. Navigate to the storefront directory
cd theethrealpalatte

# 2. Install dependencies
npm install

# 3. Launch local development server
npm run dev
```

For production builds:
```bash
cd theethrealpalatte
npm run build
```
